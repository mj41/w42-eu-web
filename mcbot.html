mcbot.w42.eu

Minecraft robots that play vanilla survival on their own: wood, tools, a shelter before the night, food, iron, a wheat field by the water. The goal is a robot that lives through a week of game days without dying. A proof of concept, vibe coded, not reviewed by humans yet.

mon.mcbot.w42.eusign in

The dashboard: every run live and replayed, the land it has seen, a 3D view from its eyes, and what it plans and does. Sign in with GitHub or Google and ask to watch; mj41 approves.

Day 1 of a week run: the robot has dug a shelter, put a chest and a furnace in it and holds a stone axe. Click for the full size.

How it is tested

Each run starts a fresh vanilla server and lets the robot play; the clock moves on while it only waits for the night to pass. A new robot reaches a running test as a signed commit, built where it runs, and every run is kept, so it can be replayed and compared with the next one.

Source

  • go-mc26-kit: the bot framework the robots are built on, with examples. MIT
  • go-mc26: a Go library for Minecraft 26.x, generated from each release. MIT
  • mc26: the pipeline that extracts the data and generates the library, and the end-to-end tests. MIT
