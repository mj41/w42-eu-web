Your robot for your own programs and AI agents, and a Go kit for writing new robot apps. dev.sa.w42.eu is coming online soon; you can run it at home today.

Run it at home (GitHub) Set up a robot
  • A script in any language shows text on the robot, nods, lights the LEDs as a progress bar, plays a chime: one curl each, no robot protocol to learn.
  • An AI agent (Claude Code or any MCP client) shows short text, speaks in a bubble, asks you "Deploy now? Yes / Not yet" and gets the button you tapped, and hears when you pat the robot's head or hold a tag near it.
  • App authors (Pet, Focus, the next one) use the same building blocks in Go, so a new robot app is a few hundred lines instead of a few thousand.

Two lines to start

A script shows a green card on the robot:

curl -X POST $DEV/v1/robots/$ROBOT/show -H "Authorization: Bearer $KEY" \
  -d '{"title":"Build","text":"All tests pass","color":"green","progress":1}'

Claude Code gets a body on your desk:

claude mcp add --transport http stackchan $DEV/mcp --header "Authorization: Bearer $KEY"

Dev's page makes the key and shows both lines with your robot and address filled in.

The actions

Every action is POST /v1/robots/<robot>/<action> with a JSON object, and the same action is the MCP tool robot_<action>.

  • show a card with text that sizes itself, a progress bar, or a picture; say a speech bubble; face an emotion, or the robot's own readings.
  • move the head (nod, shake, or yaw and pitch); leds a colour, a bar or an effect; sound a chime or a few notes.
  • ask a question with 2 to 4 buttons and get the answer tapped.
  • events: what a person did: a tap, a pat or a stroke on the head, shaken, picked up, someone near, a tag, a TV remote's button.
  • state (online, its readings), and command for any of the robot's own commands, except switching its apps, restarting it, or turning streams on.

Keys

A key belongs to one robot, and only a browser paired with that robot (by its QR code) makes one. Dev keeps only a hash of it, lists your keys with when each was last used, and deletes them. For a robot set up by a manager, its keys show on the manager's page next to its paired browsers, and can be removed there too.

For app authors: the Go kit

  • robothub: the robot side of an app: tokens, one connection per robot, pairing codes.
  • robot: cards, the face, the head, the LEDs, sounds on a connected robot.
  • screen, sound, leds: 320×240 cards and questions, chimes and melodies, the LEDs in the robot's order.
  • gesture: the robot's raw events as what a person did.

The packages

Start

  1. Run Dev on a computer at home (one Go binary or a container), until dev.sa.w42.eu is online.
  2. Give your robot Dev as one of its apps: with the home manager, or over USB.
  3. On the robot, switch to Dev and scan its QR code with your phone or computer.
  4. New key on Dev's page: it is shown once, with a curl line to try and the line that gives it to Claude Code.
